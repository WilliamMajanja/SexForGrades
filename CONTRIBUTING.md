# Contributing to SexForGrades

SexForGrades is a student-run liberation tool. Contributions must align with our principles:

- **Evidence-based**: Focus on verifiable facts and public records
- **Privacy-first**: No telemetry, no data exfiltration
- **Safety-focused**: Never compromise student safety or enable harassment
- **Systems-focused**: Target structures (patronage, commodification), not individuals for personal attacks
- **Open & auditable**: Keep it zero-dependency and readable
- **Mass line**: From the masses, to the masses

## How to Contribute
1. Fork the repo
2. Create a feature branch
3. Test thoroughly
4. Submit a PR with clear description

## Code of Conduct
- Solidarity with oppressed students
- Respect for safety and consent
- No doxxing or harassment
- Focus on liberation
